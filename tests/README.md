# Tests

This directory contains automated tests for the project.

## Before pushing

Run the project's available test suite locally before pushing changes.

At minimum:

1. Run all relevant tests.
2. Run formatting and linting checks if the project uses them.
3. Verify that the project builds or starts successfully when applicable.
4. Check that no secrets, generated files, or unrelated changes are included.
5. Review the final diff before pushing.

The exact commands depend on the language and tooling used by the project. Update this file when project-specific test commands are added.
