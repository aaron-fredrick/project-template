# Code of Conduct

## Expected behavior

Contributors are expected to:
- Be respectful and constructive.
- Focus on the work and technical discussion.
- Accept reasonable differences in experience, background, and opinion.
- Keep discussions professional and relevant.

## Unacceptable behavior

Harassment, discrimination, personal attacks, threats, or other abusive behavior is not acceptable.

## Reporting

Report serious conduct concerns privately to the project maintainers. Do not use public issues for sensitive reports.

Project maintainers may take reasonable action to address behavior that violates this code of conduct.
